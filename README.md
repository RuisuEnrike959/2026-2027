# Campus Student Management

A small Django project for managing student records. It demonstrates models, PostgreSQL, migrations, and CRUD operations.

## Project structure

- `config/`: project settings and root URL configuration.
- `students/`: student model, form, views, routes, admin, tests, and migrations.
- `templates/`: English pages rendered by Django.
- `static/css/`: styles for the site.
- `venv/`: local Python virtual environment (created during setup and ignored by Git).
- `__pycache__/`: Python-generated bytecode folders; they appear automatically when the project runs and are ignored by Git.

## Setup on Windows PowerShell

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

By default, the project uses SQLite so it can run without a database server:

```powershell
python manage.py migrate
python manage.py runserver
```

Open <http://127.0.0.1:8000/>.

To load the five sample students from the lesson after migrating, run:

```powershell
python manage.py loaddata demo_students
```

## Use PostgreSQL

Create the `school_user` role and `school_db` database in PostgreSQL, then set the connection values in PowerShell before starting Django:

```powershell
$env:DB_ENGINE = "postgresql"
$env:DB_NAME = "school_db"
$env:DB_USER = "school_user"
$env:DB_PASSWORD = "your-postgres-password"
$env:DB_HOST = "127.0.0.1"
$env:DB_PORT = "5432"
python manage.py check --database default
python manage.py migrate
python manage.py runserver
```

Do not commit database passwords. `.env.example` lists the expected variable names; Django reads these values from the process environment.

## Student model and migrations

The `Student` model is in `students/models.py`. When you change it, create and apply a migration:

```powershell
python manage.py makemigrations students
python manage.py migrate
python manage.py showmigrations students
```

The initial migration creates the table. The optional phone field is included in the initial schema.
