Responsive Web Design / レスポンシブウェブデザイン

Adaptable site for all devices / すべてのデバイスに対応するサイト

This example uses fluid layout and responsive grids to work well on desktop, tablet, and mobile. / この例は、デスクトップ、タブレット、モバイルですべてうまく表示されるように、フルイドレイアウトとレスポンシブグリッドを使用しています。

1

Fluid layout / フルイドレイアウト

Columns adjust to screen size to use available space. / カラムは画面サイズに合わせて調整され、利用可能なスペースを活用します。

2

Breakpoints / ブレークポイント

Content shifts from 3 to 2 to 1 column at different widths. / コンテンツは幅に応じて 3列、2列、1列に変化します。

3

Mobile First / モバイルファースト

We design for mobile first, then enhance for larger screens. / まずモバイルを中心に設計し、その後大きな画面向けに調整します。
